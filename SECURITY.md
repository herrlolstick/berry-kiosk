# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/herrlolstick/berry-kiosk/security/advisories/new)
instead of opening a public issue.

The admin web UI is meant for a trusted home or office network. See the
"Security" section of the [README](README.md#security) for what is protected and
how, and "Running in public spaces" for hardening a public kiosk.
